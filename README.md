معرفی پروژه

امکانات برنامه

- انتخاب عدد تصادفی
- محدودیت تعداد تلاش‌ها
- راهنمایی برای حدس‌های بزرگ‌تر یا کوچک‌تر
- امکان شروع مجدد بازی
- محاسبه امتیاز
- ثبت و نمایش رتبه‌بندی بازیکنان
